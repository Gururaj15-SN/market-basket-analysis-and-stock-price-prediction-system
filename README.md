# Market Basket Analysis and Stock Price Prediction System

## 📌 Project Overview

This project combines two data science applications: **Market Basket Analysis** and **Stock Price Prediction**. Both projects demonstrate how data analysis and machine learning techniques can be applied to real-world problems.

### 🛒 Market Basket Analysis

Market Basket Analysis is used to understand customer purchasing behavior and identify relationships between products. Transaction data is analyzed to find products that are frequently purchased together.

The **Apriori algorithm** is used to generate frequent itemsets and association rules based on **support, confidence, and lift**. These insights can be useful for product recommendations, cross-selling, inventory planning, and understanding customer preferences.

### 📈 Stock Price Prediction

The Stock Price Prediction System analyzes historical stock market data to identify trends and patterns. The project includes data preprocessing, exploratory data analysis, feature preparation, machine learning model training, and prediction.

Historical stock information is used to train the model and estimate future price movements. Data visualizations are also used to understand stock trends and compare actual and predicted values.
